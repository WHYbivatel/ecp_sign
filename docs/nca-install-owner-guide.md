# Установка выпущенного сертификата НУЦ через Tegin — инструкция владельцу заявки

Для заявки, у которой на портале статус «Выпущены сертификаты по заявке». Новая заявка не нужна.
Ключ заявки создан Tegin 0.5.3 (сборка `dd40b5e`) и хранится в зашифрованном виде в том браузере,
где проходил шаг 3.

## Перед началом

- Откройте тот же браузер и тот же профиль Chrome, где создавался ключ.
- Значок Tegin → версия 0.5.3. Если нужно обновить сборку, замените файлы в той же папке и нажмите
  «Обновить» на карточке расширения. **Не удаляйте расширение и не загружайте его из другой папки:**
  ключ заявки хранится в данных расширения.
- Найдите резервную копию ключа `tegin-nuc-….tegin-request.json`, если сохраняли её на шаге 3.
- Нужен пароль, заданный в окне Tegin при создании ключа. Восстановить его нельзя.

## 1. Установка (`importCertificate`)

1. Откройте статус заявки на `did.pki.gov.kz` (или `nca.pki.gov.kz`) и нажмите установку сертификатов.
2. Откроется окно Tegin «Установить сертификат». На каждой карточке должны быть строки
   «Цепочка до корня НУЦ РК подтверждена» и «Ключ заявки найден в этом браузере».
   - «Ключ … не найден»: нажмите «Резервная копия ключа заявки» и выберите файл `.tegin-request.json`.
   - «Цепочка не подтверждена»: остановитесь и пришлите текст причины, без ИИН и ФИО.
3. Введите пароль ключа и нажмите «Проверить и сохранить .p12».
4. Нажмите «Скачать файл ЭЦП (.p12)» и сохраните файл. Портал получает отметку об установке только
   после этого. Сразу сделайте копию файла на другой носитель.

## 2. Проверка `.p12` и подписи

1. Значок Tegin → «Подписать». Выберите безобидный документ, например текстовый файл без личных данных.
2. Выберите сохранённый `.p12`, введите тот же пароль и нажмите «Открыть ключ». Карточка сертификата должна
   показать ваш сертификат и подтверждённую цепочку НУЦ. Для проверки отзыва нужен доступ к службам НУЦ.
3. Нажмите «Подписать», затем «Проверить эту подпись». Ожидается действительная подпись.

Кнопка «Удалить ключ заявки из браузера» появляется в окне установки сразу после скачивания.
Не нажимайте её до проверки `.p12`. Запись с отметкой «установлен» можно оставить: она зашифрована
вашим паролем.

## Что сообщить исполнителю

- Статус заявки на портале после установки.
- Итог каждого пункта: успешно или текст ошибки.
- При ошибке: попап Tegin («Последний запрос», «Результат», «Причина») и, если есть, JSON из блока
  «Диагностика ошибки» (кнопка «Скопировать»). В этих данных нет ключа, пароля и персональных данных.

Не присылайте `.p12`, пароль, резервную копию ключа и снимки экрана с ИИН, БИН или ФИО.
