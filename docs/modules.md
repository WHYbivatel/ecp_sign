# Модули NCALayer в Tegin

Срез от 12 ноября 2026 года (предыдущий — 29 октября, 47 записей; с тех пор добавлен OnaiDocs Sign Bundle 1.1.0, обновлены ezSigner до 1.2.2 и SimBASE до 2.4). В каталоге **48 записей**, включая 7 обязательных системных бандлов. Это не список 48 перенесённых модулей. Статистика популярности НУЦ не опубликована; первые адаптеры выбраны по используемым государственным порталам и доступности интерфейсов.

## Что работает

| Реализация Tegin | Реализованные операции (проверены локально) | Ограничения |
| --- | --- | --- |
| НУЦ Common Utils | getKeyInfo, signXml/signXmls, CMS/CAdES из base64 и готового хеша | Не весь Common Bundle. Аргумент keyType (SIGNATURE/AUTHENTICATION) сужает выбор по правилу NCALayer ([ncalayer-reference.md](ncalayer-reference.md)); getActiveTokens всегда возвращает пустой список: токены не поддерживаются |
| НУЦ Basics | sign: XML, CMS/CAdES, raw, пакет до 10 документов | PKCS12; без токенов; XML без XPath и доподписания. raw есть и в NCALayer 0.4.10 (в wiki НУЦ его нет). Отличия формы ответа: CMS — base64 вместо PEM, raw — всегда массив |
| Госзакупки NURSign 5.1.2 | type=xml, multixml, binary, text, multitext, version | Только переданные данные; нет file, remote URL, needHash. text/multitext требуют TSA; не понижаются до BES |
| Самрук-Казына ИСЭЗ 1.0 | signXml, version | Целый XML; ответ с uid; newChain=null, повторный выбор ключа вместо кэша пароля |
| СФД QIWI 1.3 | signXml, logOut | callID сохранён; verificationResult=true выдаётся после проверки созданного XML |
| 1С-Рейтинг ЭДО 1.9.5 | getActiveTokens, getKeyInfo, signXml, createCMSSignatureFromBase64 в пространстве signUtils | Только данные в памяти; uuid сохранён |
| Uchet.kz 1.5 | commonUtils.signXml | Только целый XML; без файловых путей и API передачи пароля |
| MetaDoc 1.7 | knca.commonUtils.getKeyInfo, changeLocale | Только сведения, без подписи MetaDoc/ЕСЭДО |

Наличие адаптера **не подтверждает** полный бизнес-процесс портала. В интерфейсе каждая реализация помечена «Частично», а в реестре — `support: 'partial'`. Совместимость с eGov, кабинетом НУЦ и Tegin ЭДО описана в [portal-compatibility.md](portal-compatibility.md). Реальные операции в учётных записях не выполнялись. КНП, ЭСФ, Казначейство и остальные отсутствующие функции показаны как требующие переноса; Tegin не сообщает сайтам об их установке. Большинство сторонних модулей пока не перенесено.

## Настройки

Открыть расширение → «Модули и сервисы». Для каждой доступной реализации есть выключатель, список точных origin сайтов, разрешённые форматы, запрет обязательной TSA и лимит партии 1–10. Пустой список origin означает сайты с уже предоставленным доступом Tegin; настроить модуль не означает выдать новые разрешения. Неизвестные поля и некорректные значения отклоняются. Настройки хранятся локально, без ключей/паролей. Они перепроверяются при получении запроса, открытии подтверждения, перед подписью и перед возвратом результата. Локальные инструменты остаются независимыми от настроек портальных модулей.

## Проверки

27 Node-тестов и полный Chromium E2E: подписи через новые протоколы и форматы ответов, независимая проверка NURSign detached CAdES, RSA/ГОСТ проверка созданного XML QIWI с отрицательными тестами, каталог/поиск/навигация/узкая ширина, сохранение настроек, выключение модуля и отзыв ожидающего подписания, запрет TSA и лимит партии. Модули с неизвестными методами/параметрами, URL, XPath, токенами и полями паролей отклоняются до сохранения запроса. Реальные ключи пользователей не исследовались.

NURSign `type: "xml"` сверен с официальным кодом (`tests/nursign-xml-crosscheck.mjs`, нужны `NCA_BUNDLES` и `NCA_CORE`
из `ncalayer.zip`, по желанию `NCA_NURSIGN_JAR`). Документации модуля нет; контракт взят из подписанного JAR 5.1.2,
SHA-256 которого совпадает с каталогом: при `source: "local"` модуль подписывает `data` вызовом
`XMLUtil.createXmlSignature(SigningEntity, xml, provider)` (целый документ) и отвечает `{errorCode: "NONE", result}`.
Для RSA и ГОСТ-512 ответ Tegin той же формы, профиль подписи совпадает, кроме каноникализации (exclusive C14N у
Tegin, C14N 1.0 у NCALayer), официальный `XMLUtil.verifyXmlSignature` принимает подпись Tegin и отклоняет
изменённую. Запросы настоящих страниц Госзакупок и приём подписи их сервером не проверены.

Дополнительно выполнен `NCA_LIVE_TSP=1 node tests/e2e.mjs`: CAdES-T с реальным сервисом метки времени НУЦ, офлайн-проверка вложенной метки и NURSign type=text с обязательной меткой на искусственном документе. В сеть передавался только хеш тестовой подписи.
