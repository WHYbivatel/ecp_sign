# Матрица поддержки Tegin

Срез на 12.11.2026, ветка `codex/nca-key-issuance` после `e79613f` (проверка отзыва — этап 5). Одна таблица на сценарий и отдельная таблица
на браузер и ОС. Полная замена NCALayer заявляется только для строк, где заполнен последний столбец.

Статусы независимы друг от друга:

- **Реализовано** — код есть в расширении.
- **Проверено локально** — unit-, контрактные или браузерные тесты на синтетических ключах и
  обезличенных копиях страниц.
- **Независимый валидатор** — результат принят не кодом Tegin: Kalkan 0.7.8 (из официального
  `ncalayer.zip`, SHA-256 JAR закреплены), Kalkan XMLDSig 0.4, OpenSSL 3, xml-crypto.
- **Подтверждено на портале** — владелец своим ключом завершил операцию на настоящем портале.

## Браузеры и ОС: выпуск ключа, установка, повторное открытие `.p12`, подпись

Прогон `tests/e2e-issuance.mjs` (Chromium/Chrome/Edge) и `tests/e2e-issuance-firefox.mjs`
(Firefox) с проверкой Kalkan. В CI (`.github/workflows/ci.yml`) описаны все строки; здесь
отмечены только фактически выполненные прогоны.

| Браузер | ОС, архитектура | Результат | Где |
|---|---|---|---|
| Playwright Chromium 156 | Linux x64 | 9/9 | сервер разработки и CI, 12.11.2026 |
| Google Chrome 157 | Linux x64 | 9/9 | сервер разработки и CI |
| Google Chrome 157 | Windows x64 | 9/9 | CI ([прогон 43203864358](https://github.com/WHYbivatel/ecp_sign/actions/runs/43203864358), `e79613f`) |
| Google Chrome 157 | macOS ARM64 | 9/9 | CI, тот же прогон |
| Microsoft Edge 157 | Linux x64 | 9/9 | сервер разработки |
| Microsoft Edge 157 | Windows x64 | 9/9 | CI, тот же прогон |
| Firefox 160 (сборка `dist/firefox` с тестовыми якорями) | Linux x64, Windows x64, macOS ARM64 | 5/5 на каждой | сервер разработки и CI, тот же прогон |
| любые | Windows ARM64, Linux ARM64 | не запускалось | раннеров в CI нет |
| Safari | macOS, iOS | не реализовано | `safari-assessment.md` |

Во всех строках CI проверка Kalkan 0.7.8 выполнялась. Unit-тесты (`npm test`) проходят на Windows,
macOS и Ubuntu, полный E2E (`npm run test:e2e`) — на Ubuntu, тот же прогон. Браузеры в CI
запускаются без окна (headless).

Firefox на сайте остаётся 0.5.2: прогон выше относится к коду 0.5.3 и публикацией не является.
Firefox-прогон не покрывает перезапуск браузера, восстановление из резервной копии и отказы
чужим origin; они проверены только в Chromium.

Проверка отзыва в браузере: `tests/e2e-revocation.mjs` (Chromium, 9 сценариев) и
`tests/e2e-revocation-firefox.mjs` (Firefox 160, 4 сценария: `good`, `revoked`, откат на CRL + delta,
обе службы недоступны; 4/4 на Windows x64, macOS ARM64 и Linux x64 в CI,
[прогон 43213439114](https://github.com/WHYbivatel/ecp_sign/actions/runs/43213439114), `bae1400`). В Firefox запросы Worker расширения идут через локальный прокси с синтетическими
ответами. Разрешения хостов при временной установке выдаются сразу. Для подписанной сборки из AMO
их выдачу при установке нужно подтвердить отдельно.

## Что требуется для следующего статуса

- **Портал, установка:** владелец выполняет `nca-install-owner-guide.md` для уже выпущенной заявки.
- **Аппаратные носители:** физическое устройство и драйвер; Native Messaging отдельным компонентом.
- **ЭДО, Госзакупки, Самрук-Казына:** развёрнутый контракт или запросы страницы, полученные владельцем.
