# Tegin 0.3.2 — установка

Chrome / Edge / Chromium:
1. Распакуйте архив в отдельную папку.
2. Откройте chrome://extensions (Edge: edge://extensions).
3. Включите «Режим разработчика», нажмите «Загрузить распакованное» и выберите папку с manifest.json.
4. Обновите вкладку портала. На HTTPS-сайтах .kz адаптер включается автоматически.
5. На других HTTPS-сайтах откройте значок Tegin и нажмите «Подключить сайт».
6. При запросе подписи проверьте адрес и данные, выберите .p12/.pfx и введите пароль.

Через значок расширения доступны подпись локального файла и проверка CMS/CAdES.
NCALayer, Java и локальный сервер конечному пользователю не нужны.
Если уже запущен NCALayer, адаптер расширения обработает поддерживаемые запросы вместо него.
Ключ и пароль не сохраняются. Подписи создаются только после подтверждения.
Для метки времени передаётся хеш подписи в сервис НУЦ; ключ, пароль и документ туда не передаются.

Firefox 140+: about:debugging → «Этот Firefox» → «Загрузить временное дополнение» → manifest.json.
Такая установка действует до перезапуска Firefox. Для обычной установки нужен подписанный XPI из магазина — публикация пока не выполнена.
Фактический Firefox и конкретные госпорталы ещё не проходили сквозную проверку.

Реализована часть API NCALayer. Отзыв сертификатов (OCSP/CRL), аппаратные токены,
PAdES, XPath/доподписание XML и дополнительные модули пока не поддерживаются.
